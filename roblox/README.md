# BrainrotBattle Roblox port

This folder is the Roblox/Luau port of the current `brainrotbattle.io` game.

The web version remains untouched. The port starts by recreating the current Oldale-style overworld as a native Roblox 3D experience and then layers the BrainDex, encounters, battles, interiors and monetization on top.

## What is already implemented in this first port

- Native Roblox 3D town generated from the current 25 x 23 collision map.
- Spawn position copied from the web game.
- Collision barriers copied from the current web collision grid.
- Four landmark buildings with enter/exit prompts.
- Interior rooms in the same Roblox place.
- Tall-grass encounter zones.
- Server-authoritative encounter and battle state.
- Fight / Catch / Run battle UI.
- First five Brainwods ported with the same HP, attack and catch-rate values as the web game.
- Persistent player profile scaffold using DataStoreService.
- BrainDex/caught counts and starter ID stored server-side.
- No crypto wallet dependency.

## Open it in Roblox Studio

Recommended source-control workflow: Rojo.

1. Install Roblox Studio.
2. Install Rojo and the Rojo Studio plugin.
3. From the repository root run:

   ```bash
   rojo serve roblox/default.project.json
   ```

4. Open a blank Baseplate in Studio.
5. Open the Rojo plugin and connect to the local Rojo server.
6. Press Play.

The world is generated by `WorldBuilder.server.lua`, so a blank Baseplate is enough.

## Asset migration

The web repository contains many `.glb` assets. Roblox Studio's current importer documentation lists `.fbx`, `.obj` and `.gltf` for mesh import, so the web assets should be converted/exported to a Studio-supported format before upload.

Do not commit Roblox asset IDs until the uploaded assets have passed moderation. The code is intentionally built so placeholder Parts can be replaced by Models later without rewriting gameplay.
